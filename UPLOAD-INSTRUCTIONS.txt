ALSherif Store PS4 Host — Afterglow / 14.00 / 14.02 update
=============================================================

WHAT THIS PATCH DOES
- Adds SlopKit Afterglow and its six required source modules.
- Adds firmware auto-detection and default exploit selection for 14.00 and 14.02.
- Adds the dedicated 14.0x offline cache page and manifest.
- Adds GoldHEN v2.4b18.13 and v2.4b18.14 to the GoldHEN-only selector.
- Keeps the Alsherif Store banner, branding, existing exploit chains and existing payload tools.
- Does not add PS4HEN or nexHEN as selectable HEN options.

HOW TO APPLY
1. Make a backup of your current repository folder.
2. Extract this ZIP directly into the root of your existing repository folder.
3. When Windows asks, choose "Replace the files in the destination".
4. Commit/push the replaced and new files to your existing GitHub repository.
5. After GitHub Pages finishes deploying, open the site on your PS4 and clear the browser cache / site data before testing the new firmware route.

FIRMWARE / PAYLOAD POLICY
- The new Afterglow route is exposed for firmware 14.00 and 14.02.
- Firmware 14.02 is restricted to GoldHEN v2.4b18.14.
- Firmware 14.00 allows v2.4b18.13 or v2.4b18.14.
- The existing 13.52 GoldHEN restriction is intentionally unchanged because this repository does not bundle v2.4b18.11.
- The Afterglow source itself contains a 13.52 table, but this site's GoldHEN gate prevents offering an unsupported 13.52 HEN path.
